    Online Shopping Behaviour Analytics System

    A NoSQL (MongoDB) analytics project that studies how visitors behave in an online store and which sessions end in a purchase. Each browsing session is one document; the dashboard aggregates them by month, visitor type, region and behaviour.

    { month: "Nov", visitorType: "New_Visitor", region: 3, weekend: false,
  trafficType: 2, specialDay: 0.0,
  administrative: 2, administrativeDuration: 40.5,
  informational: 0, informationalDuration: 0,
  productRelated: 31, productRelatedDuration: 1450.2,
  bounceRate: 0.004, exitRate: 0.02, pageValues: 18.6,
  revenue: true }

    How to use

    • Pick filters in the sidebar and press Apply Filters.
    • Upload a CSV with the UCI “Online Shoppers Purchasing Intention” columns, or use the built-in sample.
    • Use Performance Test to show why indexes matter.

    Stack

    • Database: MongoDB (document model)
    • Backend: Node.js + Express (aggregation endpoints)
    • Frontend: this dashboard, Chart.js
